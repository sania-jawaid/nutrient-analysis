One linked research workflow

Explore the data. Validate the inputs. Inspect extraction evidence.

01 / Understand & link

Audit the complete local product snapshot, then match the annotated nutrition-image inventory by exact string barcode.

A barcode match does not establish packaging-image equivalence. Leading zeros are retained.

02 / Prepare & extract

Inspect original pixels, supplied OCR words, normalized boxes and local tokenizer lengths before CPU BIO inference.

Original words, gold tags and official splits are preserved. No retraining or metadata-as-gold.

This is a frozen presentation snapshot, not the live Streamlit application. Charts, navigation, product search and saved examples work offline. Inference, image uploads and live refresh do not.

Measured preprocessing decisions

Required: retain sliding windows, original word alignment and independent geometry checks. Optional enhancements need paired OCR validation against independent transcription. Scope, provenance & responsible interpretation

What this file contains

  • Measured summaries and saved model outputs from the local project.
  • Embedded Plotly JavaScript, charts, searchable product metadata and six image/prediction examples.
  • A frozen full-cohort progress snapshot; it does not update when the live run advances.
  • No weights, inference runtime, secrets or absolute local image paths.

What is intentionally unavailable

Live model execution, new-image OCR, uploads, external image fetching and server-side Streamlit filters. Use the original local application for those workflows.
